# Fluffy Butt Farm

Single-page website for Fluffy Butt Farm — a veteran-owned family pastured-poultry farm in Cameron, West Virginia (Marshall County, on the Ohio line). Owner: Allen Hager.

- **Phone:** (304) 281-1290
- **Address:** 1016 Wolf Run Rd, Cameron, WV 26033
- **Email:** alyssalee44.ah@gmail.com (from the Facebook page)
- **Facebook:** https://www.facebook.com/p/Fluffy-Butt-Farms-100092992433733/
- **Online store (Square):** https://fluffybuttfarmwv.square.site/

## Structure

- `index.html` — the whole site (inline CSS, no build step). Palette taken from the farm's own seal: sunflower yellow + navy, with pasture green. Alfa Slab One / Libre Franklin / Caveat. Light and dark themes.
- `img/` — the farm's own photos (Square store gallery + Google Business Profile) and the "Food That Matters" seal logo.

## Sections

Hero · highlights strip · our farm (Intelligencer quote) · how we raise them · products (9 items from the Square catalog) · farm-to-table photos · gallery · how to order · contact + map.
